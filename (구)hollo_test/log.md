1단계 (데이터 기반 다지기: 장소 데이터 스키마 & DB 구축)을 완료했습니다! 🎉

기획서에 명시된 10대 핵심 지표와 뚜벅이 내향인의 특성을 온전히 반영한 데이터셋과 서비스 로직을 완성했습니다.

📂 1단계 구축 완료 파일


config.py

4단계 에너지 레벨 (🪫방전 ~ 🔋활동적) 및 에너지별 추천 스팟 개수, 동적 가중치 사전 정의
5대 목적별 페르소나 (생각정리형, 문화감상형, 카페체류형, 자연회복형, 가벼운 탐방형) 메타데이터 정의


data/places.json

총 12개 대표 힐링 여행지 (강릉 송정, 춘천 의암호, 파주 출판도시, 수원 성곽길, 양평 두물머리, 인천 배다리, 군포 수리산, 원주 뮤지엄산, 속초 영랑호, 부여 백마강, 동두천 소요산, 서산 개심사)
10대 Feature 점수 (1~5점):
quietness(한적함), public_transport(대중교통), walking(걷기), solo_dining(혼밥), solo_cafe(혼카페), nature(자연), culture(문화), stayability(체류성), interaction_need(상호작용 부담도), fatigue(피로도)
뚜벅이 상세 이동 정보: 소요시간(분), 환승 횟수, 배차 간격, 난이도
저자극 시간대별 코스 (Itinerary): [역 도착 → 산책 → 혼밥 → 카페 → 귀가] (스팟별 자극도 stimulus 명시)
큐레이터의 다정한 한 줄 팁 (curator_note)


services/place_service.py

데이터 로드, 단건 조회, 그리고 1단계 Hard Filter (최대 이동시간, 테마, 페르소나) 필터링 함수 구현
🔍 데이터 샘플 확인 (예: 강릉 송정 솔밭길)
json
{
  "name": "강릉 송정해변 솔밭길 & 송정 바다",
  "scores": {
    "quietness": 4.5,          // 한적함

    "stayability": 4.7,        // 머물기 좋음
    "interaction_need": 1.2,   // 상호작용 부담 최저
    "fatigue": 2.2             // 피로도 낮음
  },
  "transit": {
    "route": "KTX 서울역/청량리역 → 강릉역 (1시간 40분) → 시내버스 223번 (15분)",
    "total_minutes": 115,
    "transfers": 1,
    "difficulty": "쉬움"
  },
  "curator_note": "사람 바글거리는 안목 메인 거리에서 딱 10분만 솔밭길로 걸어오세요. 파도 소리만 들리는 진짜 나만의 바다가 펼쳐집니다."
}

기획서의 4단계 추천 알고리즘 로직이 

core/recommender.py
에 완벽히 구현되었습니다.

⚙️ 구현된 4단계 추천 파이프라인
text
[입력: 에너지 상태, 선호 테마, 인파 민감도, 이동 한계시간]
   ↓
Step 1. Hard Filter (대중교통 이동시간 초과 후보 원천 배제)
   ↓
Step 2. Dynamic Scoring (에너지 상태에 따라 가중치를 실시간 재조정하여 점수화)
   ↓
Step 3. Diversity Top 3 (1~3위가 모두 똑같은 테마가 되지 않도록 분산 선별)
   ↓
Step 4. Course Adapter (에너지 🪫방전 시 2곳 압축, 🙂보통 시 3~4곳 코스 자동 조절)
   ↓
[출력: 상위 3곳 여행지 + 맞춤 타임라인 코스 + 별점/환승 태그]
🧪 알고리즘 검증 테스트 결과
실제 시뮬레이션 테스트를 수행하여 의도한 대로 동작함을 확인했습니다.

1️⃣ 시나리오 A: 에너지 🪫 방전 + 바다 선호 + 인파 절대 회피
1위: 강릉 송정해변 솔밭길 (바다/해변) — 점수: 8.47점
👉 에너지가 방전 상태이므로 원래 5개였던 코스가 [소나무 숲 벤치 바다멍 → 통창 오션뷰 북카페] 2개 핵심 저자극 코스로 자동 압축됨!
2위: 군포 초막골 생태공원 (자연/숲길) — 점수: 8.07점 (소요 45분, 환승 0회)
3위: 춘천 의암호 물레길 (호수/수변) — 점수: 7.93점
결과: 바다/숲/호수로 테마 다양성(Diversity)이 확보되고, 이동 스트레스가 적은 곳들이 정확히 추천되었습니다.
2️⃣ 시나리오 B: 에너지 🙂 보통 + 문화/책 선호 + 이동 100분 이내
1위: 파주 출판도시 (문화/서점) — 점수: 8.65점 (코스 3개)
2위: 인천 배다리 헌책방 골목 (문화/골목) — 점수: 8.40점 (코스 3개)
3위: 원주 뮤지엄 산 (문화/건축) — 점수: 7.78점 (코스 3개)

🧩 3단계 구축 완료 모듈


core/prompts.py

내향인 큐레이터 '홀로(Hollo)'의 차분하고 사려 깊은 대화 톤앤매너 정의
자연어 질의에서 여행 조건을 추출하는 슬롯 추출 프롬프트
사용자 에너지 상태와 추천 이유를 엮어주는 감성 브리핑 생성 프롬프트


core/extractor.py

긴 설문조사 없이 일상 대화문("서울에서 이번 주말에 혼자 바다 보러 가고 싶어. 사람 많은 데 말고 조용한 곳으로.")을 입력받아 출발지, 여행일, 에너지 레벨, 인파 민감도, 희망 테마, 이동 시간을 자동 추출
이중 안전장치: OpenAI LLM 연동 + API 지연/오류 시에도 즉시 100% 작동하는 규칙 기반(Rule-based) Fallback 내장


core/curator.py

슬롯 추출 ➡️ 4단계 동적 랭킹 엔진 ➡️ 감성 맞춤형 브리핑 합성을 한 번에 실행하는 메인 큐레이터 오케스트레이터
🔍 실제 동작 검증 결과
사용자 입력:
"서울에서 이번 주말에 혼자 바다 보러 가고 싶어. 사람 많은 데 말고 조용한 곳으로."

text
1. 자동 추출된 조건 (Extracted Slots):
   - 출발지: 서울
   - 에너지 상태: LOW (조금 쉼)
   - 인파 민감도: 최대한 피하고 싶어요
   - 선호 테마: ['바다']
   - 최대 이동시간: 120분
2. AI 큐레이터 브리핑 (OpenAI 생성):
   "안녕하세요. 이번 주말, 사람들의 시선에서 벗어나 온전히 쉴 수 있는 세 곳의 쉼터를 골라보았습니다. 
   여러분의 에너지가 조금 쉼을 필요로 하고 있다는 것을 잘 알고 있습니다. 
   각 여행지는 사람의 소음이 적고, 자연의 소리에 귀 기울이며 가벼운 산책을 즐길 수 있는 공간으로, 
   편안한 마음으로 휴식을 취할 수 있도록 돕습니다. 바다의 고요함 속에서 자신만의 시간을 찾아보시기 바랍니다."
3. 추천된 Top 3 저자극 여행지:
   [1위] 강릉 송정해변 솔밭길 & 송정 바다 (바다/해변, 115분, 환승 1회)
   [2위] 군포 초막골 생태공원 & 수리산 숲길 (자연/숲길, 45분, 환승 0회)
   [3위] 춘천 의암호 물레길 & 삼천동 수변 (호수/수변, 82분, 환승 1회)

사이드바 제거 및 다크 글래스모피즘 & 노을빛 앰비언트 글로우 감성 UI 개편을 완벽하게 적용했습니다! ✨

단순한 블랙 화면이 아닌, '방구석의 포근함'과 '노을빛 여행의 설렘'이 공존하는 깊이 있는 서정적 갤러리 UI로 탈바꿈했습니다.

🌌 주요 개편 내용
1. 사이드바 완전 제거 ➡️ 플로팅 컨트롤 덱 (ui/control_deck.py)
답답했던 왼쪽 사이드바를 완전히 제거하고 메인 화면의 흐름에 자연스럽게 녹아들도록 일원화했습니다.
플로팅 컨트롤 덱: 5대 페르소나 선택, 편도 최대 이동시간 슬라이더, 테마 필터, 인파 민감도 옵션이 필요할 때만 가볍게 열어볼 수 있는 세련된 글래스 바로 재배치되었습니다.
2. 딥 차콜 & 노을빛 앰비언트 글로우 테마 (app.py)
배경: 인위적인 순수 블랙 대신 깊이 있는 딥 차콜/인디고 네이비(#0b0d14) 베이스에 **따뜻한 노을빛 앰버(rgba(249, 115, 22, 0.09))**와 로즈골드·은은한 인디고가 겹쳐지는 은은한 빛 번짐(Ambient Radial Glow) 효과를 구현했습니다.
글래스모피즘(Glassmorphism): 상단 네비게이션, 브리핑 박스, 카드에 backdrop-filter: blur(16px)와 섬세한 반투명 테두리(rgba(255, 255, 255, 0.08))를 적용해 마치 어두운 방 안에서 빛나는 유리 오브제 같은 감성을 연출했습니다.
타이포그래피: "오늘, 혼자 뭐하지?" 타이틀에 석양의 온도를 담은 골드-오렌지 그라데이션 텍스트를 입혔습니다.
3. 비율 왜곡 없는 이미지 쇼케이스 갤러리 (ui/recommendation_card.py)
고화질 힐링 사진이 어떤 화면 크기에서도 찌그러지지 않도록 **aspect-ratio: 16/10과 object-fit: cover**를 엄격히 적용했습니다.
마우스를 올리면 사진이 부드럽게 살짝 확대되는 감성적인 마이크로 인터랙션을 더했습니다.
뱃지와 큐레이터 노트 박스 역시 따뜻한 앰버오렌지 톤으로 은은하게 빛나도록 다듬었습니다.
4. 다크 앰비언트 지도 시각화 (ui/map_view.py)
Pydeck 지도를 다크 모드로 전환하고, 마커 핀 또한 **1위(따뜻한 노을 앰버), 2위(로즈골드), 3위(은은한 트와일라잇 인디고)**로 맞춰 밤하늘의 별처럼 위치를 짚어줍니다.

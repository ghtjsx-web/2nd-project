# 2nd-project : 대한민국 축제 & 로컬 상생 힐링 여행 큐레이터

AI 기반 맞춤형 축제 큐레이션 및 지역 소상공인(착한가격업소) 상생 힐링 여행 서비스

---

## 🚀 실행 방법
```bash
streamlit run app.py
```

---

## 🌟 주요 핵심 기능 (데이터 파이프라인 & AI 큐레이터)
1. **🎉 전국 축제 1,320건 & 문화행사 통합 RAG 파이프라인**
2. **🍽️ 행정안전부 착한가격업소 연계** (미용실/세탁소 등 비외식 업종 정밀 필터링)
3. **📸 축제 맞춤 인생샷 포토스팟** (지형 사실 기반 정밀 매칭 및 2중 안전장치 할루시네이션 방어)
4. **🌲 문체부 인증 웰니스 힐링지 & 인근 공영주차장 연계** (체력별 4단계 맞춤 타임라인)
